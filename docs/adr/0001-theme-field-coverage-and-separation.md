# Theme field coverage and adjacent-region separation

Status: accepted.

The theme workflow will treat Plan Palette generation as the highest shared Seam, use a small set of semantic Visual roles, and maintain a versioned Field inventory for all six Targets. Same-semantic fields may share colors, but adjacent UI regions require measurable separation; passive regions target 1.2:1 and interactive boundaries target 3:1 while text retains its existing contrast targets. This balances complete public-field coverage with a coherent palette, avoids per-field color noise, and makes unsupported version-specific fields visible as partial rather than silently omitted.
